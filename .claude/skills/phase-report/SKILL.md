# phase-report — 제출용 보고서 초안 생성

## 목적
지정한 phase의 README와 images, incident-log를 종합해 교육 제출용 보고서 초안(마크다운)을 만든다.

## 절차
1. 대상 phase를 확인한다 (인자 예: `phase2`). 미지정 시 전체 3개 phase를 대상으로 한다.
2. 해당 phase README에서 완료된 항목만 추려 다음 구조로 재구성한다:
   - **개요** — 목표, 대상 시스템, 수행 일시
   - **수행 내역** — 항목별: 명령/절차 → 결과 → 탐지 여부
   - **탐지·대응 분석** — Snort 시그니처, Splunk 통계, 방화벽 정책 변화
   - **결론** — 확인된 취약점/탐지율/대응 효과
3. images/ 폴더의 캡처를 관련 섹션에 상대경로로 삽입한다.
4. 결과를 `phaseN-attack/report-draft.md` 같은 새 파일로 저장하고, 원본 README는 건드리지 않는다.
5. 아직 비어있는(미완료) 항목은 보고서 말미 "미완료 항목" 목록으로 분리 표기한다.

## 출력 형식
- 순수 마크다운. 표와 코드블록 활용.
- 제목: `# [PhaseN] SIEM 실습 보고서`

# 협업 (Collaboration) — 참고 자료

> **상태: 미확정.** 이 폴더는 나중에 다른 사람과 **협업하게 될 경우** 쓰기 위해 미리 정리해 둔 참고 자료다.
> 협업이 확정되기 전까지는 실행하지 않아도 된다.

## 협업하기로 정해지면

1. **환경 접근 방식 결정** — 환경세팅 가이드에서 A(원격 데스크톱)·B(Tailscale)·C(OVA) 중 선택
2. **역할·계정 분리** — 관제(Blue)/컨설팅(Red) 역할과 Splunk·pfSense 계정 분리
3. **스터디 방식 합의** — 스터디 가이드의 역할 분담·진행 순서 참고
4. 실제 계정·IP·이름에 맞춰 위 두 문서를 구체화
